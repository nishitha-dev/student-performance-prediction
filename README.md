# Student Performance Prediction

This project uses **Machine Learning (Linear Regression)** to predict a student’s **final exam score** based on:

- Hours Studied  
- Attendance Percentage  
- Previous Academic Score  

It helps analyze how these factors influence overall student performance.

---

## Technologies Used

- Python  
- Pandas  
- Scikit-learn  
- NumPy  

---

## How It Works

1. The dataset is loaded using **Pandas**  
2. Important features are selected:
   - Hours studied  
   - Attendance  
   - Previous score  
3. The data is split into training and testing sets  
4. A **Linear Regression** model is trained  
5. The model predicts the student’s final score  
6. **Mean Absolute Error** is used to measure accuracy  

---

## Model Used

### Linear Regression  
The model learns the relationship between study habits, attendance, and past performance to predict the final score.

---

## Model Performance

The model achieved a **low Mean Absolute Error**, which indicates good prediction accuracy for the given dataset.
