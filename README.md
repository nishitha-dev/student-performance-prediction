# student-performance-prediction
This project uses Machine Learning (Linear Regression) to predict a student’s final exam score based on:

Hours studied

Attendance percentage

Previous academic score

It helps analyze how these factors influence student performance.

Technologies Used

Python

Pandas

Scikit-learn

NumPy

Model Used

Linear Regression

The model learns the relationship between study habits, attendance, and past performance to predict the final score.

Model Performance

The model achieved a low Mean Absolute Error, indicating good prediction accuracy for the given dataset.
